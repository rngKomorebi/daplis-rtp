daplis_rtp.gui.tabs.single_pixel_histogram module

Single-pixel histogram: when in the cycle one pixel’s photons arrive.

Used to check that the output is homogeneous. A healthy pixel fires at a steady rate through the acquisition window, so its histogram has a flat top; a sloping or truncated one says the readout is filling up, or that the light is not steady.

The unpacking lives here rather than in the canvas, which is where it used to be. A plot widget that cannot be drawn without a LinoSPAD2 file on disk is one that cannot be tested, and the firmware version and the timestamp count it needs are chosen on this tab anyway.

plotted_data()[source]

The numbers behind the plot, for File -> Export.

Returns None when there is nothing to export, or a dict:

stem

A suggested file name, without an extension.

columns

Ordered {heading: 1-D array}; every column the same length.

notes

Lines describing where the numbers came from, written into the file as # comments so that a plot found on a disk six months later can still say what it was.

refresh()[source]

Read the newest file and rebuild the histogram.

There is no stream on this tab: a histogram is something to look at, not something to watch move. The button reads the newest file every time it is pressed, so a run in progress is followed by pressing it again.
