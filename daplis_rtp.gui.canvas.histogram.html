daplis_rtp.gui.canvas.histogram module

Timestamp histogram for one pixel.

Used to check that the output is homogeneous: the histogram of a healthy pixel has a flat top.

The canvas takes the numbers already extracted. That is a change from the old HistCanvas, which opened and unpacked the data file itself - a plot widget that could not be drawn without a LinoSPAD2 file on disk, and a file reader that could not be tested without a window. The unpacking now happens in the tab, which is where the firmware version and the timestamp count are chosen anyway.
