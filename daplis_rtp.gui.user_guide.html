daplis_rtp.gui.user_guide module

The user guide window: contents on the left, the page on the right.

Not modal, like Preferences and the pixel mask: the guide is read with the tab it describes still in front of you, and a stream keeps running behind it. F1 opens it at the page of whatever tab is current, which is nearly always the question being asked.

The words live in daplis_rtp.gui.help_content; this module only shows them. The search box narrows the contents to the pages that mention a word and marks every place it occurs on the page shown - there is no index to keep up to date, so it cannot drift from the text.
