daplis_rtp.gui.tabs.online_plot module

Online plot: sensor population of one board, refreshed as files land.

The tab the application is mostly used through. A folder is chosen, the stream is started, and the plot follows the newest file in it - which is how the setup is aligned, since a change to the optics shows up on the plot within a file or two.

plotted_data()[source]

The numbers behind the plot, for File -> Export.

Returns None when there is nothing to export, or a dict:

stem

A suggested file name, without an extension.

columns

Ordered {heading: 1-D array}; every column the same length.

notes

Lines describing where the numbers came from, written into the file as # comments so that a plot found on a disk six months later can still say what it was.
