daplis_rtp.gui.help_content module

The text of the user guide, one section per page.

Kept apart from the window that shows it, and free of Qt, so that the words can be edited - and tested - without touching a widget. Each section is a small piece of HTML in the subset Qt’s rich text renders: headings, paragraphs, lists, simple tables, bold and links. No colours are set here, so the guide follows the theme like the rest of the window.

A link to another section is written <a href="#key">; the window turns it into a jump to that section rather than a scroll within the page.

The control names below are quoted exactly as they appear on screen. When a label changes in a tab, change it here too - the tests check that every tab has a section, not that the words still match.
