daplis_rtp.gui.widgets.gaussian_fit module

Gaussian fits of the lines in view, refreshed with every file.

The “Peak in view” box describes one peak, the brightest, by its shape alone. Aligning a spectrometer on a neon lamp wants more than that: every line on the sensor at once, and a width that is a fitted parameter with an uncertainty, so that a change in focus can be told apart from noise while the mirror is still being turned.

What counts as a line is decided by a threshold set by hand. Hot pixels and lines both stand above the dark floor, and nothing in one trace tells them apart reliably, but the person at the bench can see which is which - so the threshold is theirs to set, and the plot shows it as a dashed line to set it against.

A line is a run of neighbouring pixels above the threshold. Each run is fitted with a Gaussian on a constant background, over a window wide enough to see the background on either side, then fitted again over four sigmas of what the first fit found. Two lines close enough that the trace never drops below the threshold between them are one run and one fit: raise the threshold to split them.

The arithmetic is a plain function, like peak_stats, so that it can be tested on shapes whose answers are known; the strip below only displays what it returns.

daplis_rtp.gui.widgets.gaussian_fit.fit_peaks(rates, threshold, x_lim=None, valid=None)[source]

Fit a Gaussian to every line above threshold in view.

Parameters:

  • rates (array-like) – Photon rate per pixel, indexed by pixel number.

  • threshold (float) – Rate a pixel must exceed to belong to a line.

  • x_lim (tuple, optional) – (low, high) pixel numbers, inclusive, as shown on the plot. The whole array when omitted.

  • valid (array-like, optional) – Truthy for the pixels that may be used. Masked pixels read zero, and a zero inside a line would drag its fit down, so they are left out of the fit rather than fitted as data.

Returns:

One per line, left to right. Each has peak_pixel, low and high (the window fitted). A successful fit adds amplitude, centre, sigma and background, and centre_err and sigma_err - None where the fit could not say. A failed one has error instead, saying why.

Return type:

list of dict
