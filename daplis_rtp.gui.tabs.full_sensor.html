daplis_rtp.gui.tabs.full_sensor module

Full Sensor: both halves of the LinoSPAD2 sensor, 512 pixels at once.

Two boards, each writing into a directory of its own, plotted end to end with a dashed line marking the seam. Pixel-address correction is always applied to board 2 and never to board 1, as the sensor geometry requires, so no switch is offered for it; the same holds for the absolute timestamps, which full-sensor data are always collected with because they are what synchronizes the two halves.

Both browse rows are used here, which is why every other tab reserves two as well: the plot has to begin at the same height on all five.

presetmask_pixels()[source]

Apply each board’s recorded warm-pixel mask, or lift them.

Each board uses the shared daughterboard and its own motherboard to look up its file. A board with no mask recorded is skipped silently; the warning comes only when neither has one, since one board masked and the other not is a perfectly ordinary state.
